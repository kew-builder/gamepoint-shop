# 💸 GamePoint Shop

> Full-stack Web Application  
> Angular + ASP.NET Core + QR Payment (PromptPay)

โปรเจคนี้เป็นตัวอย่างระบบขาย Digital Product / Game Point  
รองรับการชำระเงินด้วย QR Code และทำงานอัตโนมัติผ่าน Webhook

---

## ✨ Features
- เลือกแพ็กเกจสินค้า
- ชำระเงินด้วย PromptPay QR
- อัปเดตสถานะการจ่ายเงินอัตโนมัติ
- ระบบ Wallet / Point
- Order History
- Admin Monitoring (พื้นฐาน)

---

## 🧱 Tech Stack

### Frontend
- Angular
- Tailwind CSS

### Backend
- ASP.NET Core Web API
- RESTful API

### Database
- SQL Server / SQLite

### Payment
- Omise (Opn Payments)
- PromptPay QR
- Webhook
